# LLM Bias Benchmark
Repository for the Open-BBQ Benchmark for Large Language Models in Open-Ended Settings.

## Dependencies
There is only one library required for Python to generate the results.

```bash
pip install matplotlib
```

## Generate the results

```bash
python3 calculate_results.py
```
[calculate_results.py](calculate_results.py) will calculate accuracy, bias score, and unknown rate for 4 models including GPT-4o, o3-mini, Gemma-3, and Llama-3.1.<br>
The results will be plot tables and saved to [result_plots](result_plots) folders.<br>
This code will also calculate the results of filler items.

## Project structures
The [data](data) folder contains the baseline/benchmark data for each model.<br>
The [debiasing](debiasing) folder contains the debiasing data/prompts for each model.<br>
The [evaluation](evaluation) folder contains the evaluation data/prompts.<br>
The [filler_items](filler_items) folder contains filler items.<br>
The [metadata](metadata) folder contains the original metadata of BBQ dataset.<br>
The [results](results) folder contains the results that generated by each model.<br>
The [result_plots](result_plots) folder contains the results graphs/plots.

[assess_evaluation_correct_rate.txt](assess_evaluation_correct_rate.txt) contains human-annotated evaluation results.<br>
**Label:T** indicates evaluation method correctly understands the results and returns the correct option.<br>
**Label:F** indicates evaluation method returns the wrong option.<br>
The accuracy of evaluation method is: the number of Label:T is 1559 and the number of Label:F is 41, so 1559/1600 = 97.74%
